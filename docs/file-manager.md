# File Manager

CorePanel provides a tenant-aware file manager built around the package’s media layer.

## Features

- upload
- grid view
- list view
- image and PDF preview
- download
- delete
- metadata
- collections
- optional folders

## Controls

- max upload size from settings
- allowed MIME types from settings
- policy-based access checks

## Tenancy behavior

- `single`: normal storage paths
- `tenant-id`: tenant-prefixed paths
- `multi-db`: tenant DB metadata plus tenant-prefixed paths
