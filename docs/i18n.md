# Internationalization

CorePanel supports localized UI labels and localized setting values.

## Main concepts

- package translation files
- current locale resolution
- fallback locale resolution
- localized settings
- localized form schema labels and messages

## Installer questions

The installer asks for:

- default locale
- fallback locale

## Frontend behavior

- Vue uses `laravel-vue-i18n`
- the document language is updated on locale changes
- locale switching uses a CorePanel route instead of hardcoded URLs

## Builder behavior

FormBuilder supports:

- `labelTranslations`
- `placeholderTranslations`
- `helpTranslations`
- `validationMessageTranslations`
- `optionTranslations`

## Tip

Keep the fallback locale populated for operational messages and validation responses. It avoids partial UI gaps when a translation set is incomplete.
